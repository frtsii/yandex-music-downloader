# Changelog

## 3.5.4

- Added the Flutter Windows interface with English and Russian localization.
- Added portable clean-system packaging and bundled Visual C++ runtime libraries.
- Added expandable collection history with track, album, playlist, and artist artwork.
- Changed progress reporting from input links to individual tracks.
- Added current UUID playlist URL support.
- Added synchronized lyrics fallback through NetEase, LRCLIB, QQ Music, and KuGou.
- Added readable genre names and Windows-safe punctuation handling.
- Added monochrome mode, animated background, local settings, and OAuth storage.
