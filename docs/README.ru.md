# Загрузчик с Яндекс Музыки

Портативное приложение для Windows с интерфейсом на Flutter и поддержкой синхронизированных текстов песен.

> Это независимый некоммерческий проект с открытым исходным кодом. Он не связан с Яндексом и не одобрен им. Яндекс Музыка и её фирменные элементы принадлежат соответствующему правообладателю.

## Возможности

- Загрузка треков, альбомов, плейлистов, исполнителей и полных дискографий.
- Поддержка новых UUID-ссылок на плейлисты и классических ссылок.
- Плейлист сохраняется в одну папку; альбом — в `Исполнитель - Альбом`; дискография разделяется по альбомам.
- Обложки и метаданные встраиваются без перекодирования аудио.
- Синхронизированные тексты ищутся по порядку: NetEase, LRCLIB, QQ Music, KuGou.
- История группирует сборники и раскрывает их до отдельных треков с обложками.
- Прогресс отображается по трекам и показывает текущую операцию.
- Английский и русский языки, чёрно-белая тема и анимированный фон.

## Готовая версия

Скачайте ZIP со страницы **Releases**, распакуйте его и запустите `YandexMusicDownloader.exe`. Устанавливать Python, Flutter или Visual C++ Redistributable не нужно.

1. Откройте настройки и вставьте OAuth-токен Яндекс Музыки.
2. Добавьте ссылки — по одной на строку.
3. Выберите качество, формат текста, размер обложки и сетевые параметры.
4. Нажмите «Скачать».

По умолчанию музыка сохраняется в папку `Музыка` текущего пользователя. Настройки, история и токен находятся рядом с программой и удаляются вместе с её папкой.

## Синхронизированные тексты

Программа принимает только тексты с настоящими временными метками. Ошибка или таймаут отдельного источника не останавливает загрузку музыки. OAuth-токен не отправляется сервисам текстов.

- MP3: ID3v2.4 SYLT и USLT.
- M4A/AAC: LRC с таймкодами в теге `©lyr`.
- FLAC: LRC с таймкодами в поле `LYRICS`.

## Сборка из исходников

Нужны Windows 10/11 x64, Python 3.9+, Flutter 3.29.3 и Visual Studio 2022 Build Tools с компонентами C++.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install --upgrade pip
.\.venv\Scripts\python -m pip install . pyinstaller
.\scripts\build-windows.ps1
```

Готовый архив появится в `dist/YandexMusicDownloader-portable.zip`.
