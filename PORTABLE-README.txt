YANDEX MUSIC DOWNLOADER — PORTABLE WINDOWS BUILD

1. Extract the entire archive to a writable folder.
2. Run YandexMusicDownloader.exe.
3. Open Settings and paste your Yandex Music OAuth token.

Keep the EXE, DLL, and data folder together. No installer, Python, Flutter,
or Visual C++ Redistributable is required. Settings and the OAuth token are
stored in this folder. Delete the folder to remove the application completely.
